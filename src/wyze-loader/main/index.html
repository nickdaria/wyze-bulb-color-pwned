⚠ User Note
  • This tool is currently running out of the active OTA slot. Initiating an firmware upgrade will replace the firmware in the inactive slot (most likely Wyze). Take a backup.
  • While these bulbs are not "brickable", writing a firmware file without OTA capabilities or some sequence back to this loader OTA slot will require opening the bulb and soldering for a UART flash.

Due to the OTA nature of this loader, the partition table cannot be changed. As such, all firmware images MUST be compiled against the factory dual-OTA Wyze partition table seen below.
